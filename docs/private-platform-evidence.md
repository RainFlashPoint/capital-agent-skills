# Private Platform evidence placeholders

Cap Server/Platform 不在本开源仓库中。公开文档可以展示经维护者批准的脱敏截图或录屏，但素材必须由真实系统产生，不能由示意图冒充运行证据。

## 待人工提供的素材

1. Task 详情：只显示脱敏 Task ID、阶段、当前 Commit、Gate 和下一动作。
2. Test Action：显示 Provider 类型、精确 Commit、开始/结束时间和终态；隐藏仓库凭据、内部地址和客户数据。
3. Review Action：显示只读评审结论与 finding 数量，不展示私有源码正文。
4. Experience：显示知识 ID、来源 Task、采用结果和证据链；隐藏人员身份和组织数据。
5. 30–60 秒录屏：从候选 Commit 到 Test → Review → 完成，不剪接伪造等待或终态。

## 发布边界

- 素材提供者确认有权公开；
- URL、Token、邮箱、用户名、内网域名、客户名、仓库私有路径全部脱敏；
- 截图旁注明采集版本、日期和“私有 Platform 示例”；
- 没有素材时保留本页文字占位，不放合成界面或声称“平台已公开”。
